■ 読み方の注意

- アクションはドライランなので、実際にチケットが起票されたり担当者へ通知されたりはしていない。
- 範囲外の質問は、強制エスカレ語（④）でも情報なし検知（④'）でもない。回答は生成側の担当範囲の指示
  （verticals.SCOPE_POLICY）による断りと窓口案内で、出典 0 件なので ④ の回答ゲート
  （gates.py::_answer_gate の「未検証または出典 0 件 → escalate」）で escalate になり、⑥ で有人へ引き継いだ。
- 2026-10-07 の実行では範囲外の質問は 0.6〜2.3 秒・回答は空だった。2026-10-30 に 0-(A) を
  question_refiner.refine_question（毎回 LLM で話題 → 観点に整理）へ置き換えてからは、ほかのケースと同じく
  パイプラインを最後まで通るので、所要が延び、回答に断りと案内の文が入る。
- grace_v2（Anthropic Claude）の同じケースの実行ログは grace_v2 の docs/examples/GRACE-Support_例文4件.txt。
